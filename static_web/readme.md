# 打擊樂譜配置與樂器庫管理系統 (Percussion Score Management)

這是一個純靜態 (SPA) 網頁應用程式，專為打擊樂團的排練與演出需求設計。您可以利用此系統輕鬆規劃每首曲目的樂器配置，並快速統計每一場演出所需要的樂器總表。

---

## 🚀 第一次使用設定指南

如果您是第一次使用本系統，您**不需要撰寫或部署任何程式碼**，只要按照以下步驟建立您的專屬資料庫即可：

### 步驟一：建立您的資料庫 (Google 試算表)
1. 建立一個全新的 Google 試算表（完全空白即可！系統會幫您自動建立所有結構）。

### 步驟二：開啟權限 (非常重要)
1. 點擊試算表右上角的「**共用**」按鈕。
2. 將一般存取權更改為：「**知道連結的任何人**」。
3. 將右側的權限從「檢視者」更改為「**編輯者**」。
4. 點擊「複製連結」並完成。

### 步驟三：在網頁介面完成設定
1. 在瀏覽器中開啟專案的 `index.html`。
2. 系統會自動引導您進入 **「⚙️ 系統設定」** 頁面。
3. 將剛剛複製的 **Google 試算表網址** 貼上。
4. 點擊「儲存設定並載入資料」。
5. 系統會自動在您的試算表中建立「**樂器庫**」和「**演出資料**」兩個工作表，並寫入正確的標頭列。

恭喜您，現在可以開始使用了！所有設定只會儲存在您的本機瀏覽器中。

---

## 📖 系統操作導覽

本系統分為四個主要頁面：

### 1. 演出清單 (Performance List)
* **檢視配置**：點擊任何一首曲目，會以下拉 (Accordion) 的方式展示每個分部所分配的樂器。
* **編輯分部**：在展開的曲目中，點選任何一個分部卡片（✏️），即可重新編輯該分部的樂器配置。
* **新增配置**：點擊右下角的「+ 新增曲目/分部」按鈕，即可開啟智慧型建立器，支援拖曳樂器快速加入。

### 2. 樂器總表 (Instrument Summary)
* 用來統計與統整特定演出的所有樂器需求。
* 在上方下拉選單選擇一場演出，系統會自動幫您過濾出該場演出**所有會用到的樂器清單**，方便場務與搬運人員核對。

### 3. 樂器庫設定 (Global Instrument Pool)
* 這是系統的全域樂器資料庫。新增的樂器會被獨立存放在試算表的「**樂器庫**」工作表中。
* 這裡的樂器會自動出現在「新增配置」時的備用樂器庫中，供您隨時點擊或拖曳使用。

### 4. 系統設定 (System Settings)
* 您可以在此隨時修改綁定的 Google 試算表網址，或透過捷徑快速開啟您的資料庫。

## 📋 試算表結構 (系統自動建立)

當您第一次儲存設定時，系統會自動在您的試算表中建立以下結構：

| 工作表名稱 | 用途 | 標頭 |
|-----------|------|------|
| `樂器庫` | 存放全域樂器清單 | `樂器名稱` |
| `演出資料` | 存放演出配置資料 | `performance_name`, `piece_id`, `title`, `composer`, `arranger`, `part_name`, `instrument_name`, `instrument_remark` |

> **💡 提示：** 
> 若您在更新網頁檔案後發現畫面沒有變化，請使用強制重新整理（Windows: `Ctrl + F5` / Mac: `Cmd + Shift + R`）來載入最新版本。
