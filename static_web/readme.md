# 打擊樂譜配置與樂器庫管理系統 (Percussion Score Management)

這是一個純靜態 (SPA) 網頁應用程式，專為打擊樂團的排練與演出需求設計。您可以利用此系統輕鬆規劃每首曲目的樂器配置，並快速統計每一場演出所需要的樂器總表。系統後端完全依賴 Google Sheets (試算表) 與 Google Apps Script (GAS) 作為免費且無伺服器的資料庫。

---

## 🚀 第一次使用設定指南

如果您是第一次使用本系統，或您要將此系統部署給新的使用者/樂團，請按照以下三個步驟完成設定：

### 步驟一：準備 Google 試算表 (Database)
1. 建立一個全新的 Google 試算表。
2. 建立**兩個工作表 (Tabs)**：
   * 第一個工作表請命名為：`樂器庫`。
     * 在第一欄位 (A1) 填寫標題 `樂器名稱`。
   * 第二個工作表請命名為：`工作表1` (或任何您偏好的名稱)。
     * 在第一列 (A1 ~ H1) 依序填寫以下標題：
       `performance_name` | `piece_id` | `title` | `composer` | `arranger` | `part_name` | `instrument_name` | `instrument_remark`

### 步驟二：部署 Google Apps Script (API 後端)
1. 在剛建立好的 Google 試算表中，點選上方選單的 **[擴充功能] > [Apps Script]**。
2. 刪除編輯器內預設的程式碼。
3. 打開專案資料夾中的 `Code.gs` 檔案，將裡面的所有程式碼**完整複製並貼上**到 Apps Script 編輯器中。
4. **修改您的專屬 ID**：
   在程式碼最上方的 `SPREADSHEET_ID`，請替換為您剛剛建立的試算表的 ID (可以從試算表網址列中 `d/` 到 `/edit` 之間找到)。
5. 點選右上角的 **[部署] > [新增部署作業]**。
   * 類型選擇：**網頁應用程式 (Web App)**
   * 執行身分：選擇 **您自己 (您的 Google 帳號)**
   * 誰可以存取：選擇 **所有人 (Anyone)**
6. 點擊部署，並授權權限。部署完成後，會得到一串 **網頁應用程式網址 (URL)**，請把它複製下來。

### 步驟三：連結前端網頁
1. 使用文字編輯器 (如 VS Code) 打開專案資料夾中的 `app.js`。
2. 找到最上方的第一行程式碼：
   `const API_URL = 'https://script.google.com/macros/s/.../exec';`
3. 將剛剛複製的 **網頁應用程式網址** 貼上替換掉原本的網址。
4. 儲存檔案。
5. 恭喜！您現在只需在瀏覽器中開啟 `index.html`，即可開始使用您專屬的系統。

## 📖 系統操作導覽

本系統分為三個主要頁面：

### 1. 演出清單 (Performance List)
* **檢視配置**：畫面會列出目前所有的演出場次。展開每首曲目，可以看到各分部所分配的樂器。
* **新增配置**：點擊右下角的「+ 新增樂譜配置」按鈕，即可開啟智慧型建立器。
  * 支援**自動完成 (Autocomplete)**：輸入過的演出、曲目與分部都會自動跳出建議，並且會優先高亮「本場已建立」的曲目。
  * **拖曳與點擊選取**：在下方的「備用樂器庫」中，您可以直接把樂器標籤拖曳到特定的分部區域；如果您使用手機操作，只需「點擊標籤」就會自動加入，非常直覺。

### 2. 樂器總表 (Instrument Summary)
* 用來統計與統整特定演出的所有樂器需求。
* 在上方下拉選單選擇一場演出，系統會自動幫您過濾出該場演出**所有會用到的樂器清單**，方便場務與搬運人員核對。

### 3. 樂器庫設定 (Global Instrument Pool)
* 這是系統的全域樂器資料庫。
* 當您在這裡新增樂器後，這些樂器就會自動出現在「新增配置」時下方的「備用樂器庫」中，供您隨時拖曳使用。
* 此處新增的樂器會被獨立存放在 Google 試算表的第一個工作表 (`樂器庫`) 中，確保與實際的演出資料完全脫鉤，保持資料庫的整潔與正規化。

> **💡 開發者提示：** 
> 若您在更新網頁檔案後發現畫面沒有變化，這是因為瀏覽器會預設快取 JavaScript 檔案。請使用強制重新整理（Windows: `Ctrl + F5` / Mac: `Cmd + Shift + R`）來載入最新版本。
